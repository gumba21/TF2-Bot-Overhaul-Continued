HOW TO USE SONGS?
Paste this into your mission:
	{
		"origin" "110 10 0"
		"volstart" "10"
		"targetname" "hunter_theme" //name that you'll use to later enable the song via an input.
		"spinup" "0"
		"spindown" "0"
		"spawnflags" "49" //to make it play anywhere at the same set volume. Substract by 1 to make it only play in a set radius, substract by 32 to make it loop.
		"radius" "9999" //space where it can be played, only works if spawnflags don't include "play everywhere" aka flag 1. 
		"preset" "0"
		"pitchstart" "100"
		"pitch" "100"
		"message" "#mission/vlvx_song27.mp3" //song filename, put "ui/songname" where songname is for one of the song file names mentioned above. Custom added songs are stored in the mission folder, thus the reason why the hunter's theme has "mission" instead of "ui". Also, the # at the start of "ui" will make it so the sound in game is treated as "music" which will allow you to lower the volume of the music in the options menu.
		"lfotype" "0"
		"lforate" "0"
		"lfomodvol" "0"
		"lfomodpitch" "0"
		"health" "10" // volume
		"fadeoutsecs" "0"
		"fadeinsecs" "0"
		"cspinup" "0"
		"classname" "ambient_generic"
	}
